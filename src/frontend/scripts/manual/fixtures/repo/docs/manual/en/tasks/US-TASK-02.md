# Edit a task

Use this page to change the title of a task. The list stays correct.

## Steps

1. Open the Tasks page.
2. Click "Edit" on the first row.
3. In the "Title" field, type "Prepare the annual report".
4. Click "Update".

## What you will see

- The first row shows the new title.
