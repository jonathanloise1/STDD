# Modifica un'attività

Usa questa pagina per cambiare il titolo di un'attività. L'elenco resta corretto.

## Passaggi

1. Apri la pagina Attività.
2. Fai clic su "Modifica" sulla prima riga.
3. Nel campo "Titolo" scrivi "Prepare the annual report".
4. Fai clic su "Aggiorna".

## Cosa vedrai

- La prima riga mostra il nuovo titolo.
