# Create a task (English, to translate)

Use this page to add a task with a title. The team can see what needs to be done.

## Prima di iniziare

- Only Admin and Editor can do this.
- The list already has two tasks.

## Passaggi

1. Apri la pagina Attività.
2. Fai clic su "Nuova attività".
3. Nel campo "Titolo" scrivi un valore come "Prepare the quarterly report".
4. Nel campo "Stato" scegli "Completata".
5. Fai clic su "Crea attività".

## Cosa vedrai

- The form closes.
- The first row of the list shows "Prepare the quarterly report".

## Da sapere

- A new task always starts with status "Todo".
- This feature does not include choosing who the task is assigned to.

## Se qualcosa non va

| Cosa vedi | Cosa fare |
|---|---|
| "Il tuo ruolo non consente questa modifica." | Ask an admin of the organization for the Editor role |
| "Inserisci un titolo." | Correggi il campo "Titolo" e riprova. |
