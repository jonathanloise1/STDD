# Edit a task

Use this page to change the title of a task. The list stays correct.

## Steps

1. Open the Tasks page.
2. Click the "Edit" button on the first row.
3. In the "Title" field, type a value such as "Prepare the annual report".
4. Click the "Update" button.

## What you will see

- The first row shows "Prepare the annual report".
