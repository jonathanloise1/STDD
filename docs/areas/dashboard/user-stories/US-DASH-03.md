# US-DASH-03: Open the task list from the dashboard

| Field | Value |
|-------|-------|
| Priority | Medium |
| Feature | F-DASH-01 |
| User input | No |

## Story

**As a** team member
**I want** to go from the dashboard straight to the task list
**So that** I can work on my tasks without searching the menu

## Acceptance Criteria

1. The "Recent Tasks" section has a "View All" button; clicking it opens the Tasks page.
2. Clicking a row of the "Recent Tasks" table also opens the Tasks page.
3. The "View All" button is shown whether or not the organization has tasks.

## Access Control

| Role | Allowed |
|------|---------|
| Admin | Yes |
| Editor | Yes |
| Viewer | Yes |

## Business Rules

None.

## Error States

None.

## Non-Goals

- Opening the clicked task for editing.
- Creating a task from the dashboard.

## Questions users ask

### en

1. How do I get from my home page to the whole list of tasks?
2. Can I click on one of the items shown to open it?
3. Is there a shortcut to all the work items?
