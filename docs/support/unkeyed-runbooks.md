# Unkeyed signatures

Runbooks for log patterns that have no test case: accepted framework noise and known infrastructure conditions
with no user-visible behaviour. Format, template id rule and when to use this file:
[operations.md section 5.5](../guidelines/operations.md#55-template-runbooks-docssupportunkeyed-runbooksmd).
A failure the user can see never goes here: it gets a test case and a log key.

None.
