# Attività

L'area Attività è l'elenco di lavoro condiviso della tua organizzazione. Gli Admin e gli Editor creano le attività, le modificano, le fanno avanzare tra i vari stati e le eliminano; i Visualizzatori leggono lo stesso elenco senza modificarlo. Comincia dall'elenco delle attività, poi crea la tua prima attività.
