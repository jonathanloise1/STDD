# Aiuto

Impara a usare l'applicazione senza uscirne: leggi e cerca nel manuale, apri l'aiuto della schermata in cui ti trovi e fai domande con parole tue. Gli amministratori possono anche scaricare le domande a cui il manuale non ha saputo rispondere, per capire cosa manca.
