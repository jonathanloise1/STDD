# Organizzazioni

L'area Organizzazioni permette a un Admin di tenere aggiornati il profilo e i dati di fatturazione dell'organizzazione e di gestire le persone che ne fanno parte: vedere il team, invitare colleghi, assegnare un ruolo e rimuoverli. Gli Editor e i Visualizzatori non usano quest'area.
