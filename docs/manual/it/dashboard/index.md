# Dashboard

La Dashboard è la prima pagina che vedi dopo l'accesso. Ti saluta, mostra quante attività ha la tua organizzazione in ogni stato, elenca le attività più recenti e ti porta all'elenco completo. Admin, Editor e Visualizzatori vedono gli stessi numeri.
