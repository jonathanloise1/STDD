# Configurazione iniziale

Se accedi e non fai ancora parte di nessuna organizzazione, una procedura guidata in un solo passaggio ti chiede i dati della tua organizzazione. Quest'area spiega la pagina di configurazione e come creare la tua organizzazione. Chi fa già parte di un'organizzazione, come i colleghi invitati, non la vede mai.
